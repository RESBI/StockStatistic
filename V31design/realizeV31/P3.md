# P3 — Compute 核心（BacktestEngine 迁移 + Tier 1）实现规划

> **Phase**：P3
> **目标**：迁移 BacktestEngine + 实现 6 个 Tier 1 handler + LocalComputeBackend
> **前置依赖**：P1（Foundation）
> **预计耗时**：2 周
> **测试数**：350（含 277 项 BacktestEngine 回归）

---

## 1. 目标与范围

### 1.1 目标

建立 `stockstat-compute` 包的**核心部分**：
- LocalComputeBackend（Foundation ComputeBackend 实现）
- TaskExecutor（路由 TaskSpec 到 handler）
- Handler 注册表 + dispatch 函数
- 6 个 Tier 1 handler（indicator/backtest/grid_search/batch_backtest/monte_carlo/walkforward）
- **BacktestEngine 整体迁移**（从 V2 frontend，零修改）
- ComputeEngine + indicators 库迁移
- 硬件检测（psutil）
- Checkpoint 存储

### 1.2 不含

- RemoteComputeBackend / AutoComputeBackend（P6）
- Worker 进程（P6）
- Tier 2~7 高级 handler（P7）
- SHM/Redis 传输（P8）

### 5.1 关键回归验证

```python
# PAXG v5-redo 一致性验证
from stockstat_compute.handlers import dispatch
spec = TaskSpec(
    task_id="paxg-v5-redo",
    data_spec=DataSpec(symbols=["PAXG/USDT"], timeframe="1d"),
    compute_spec=ComputeSpec(
        task_type="batch_backtest",
        strategies={...},
        fee_models=["F1_SpotNoBNB", "F4_FutBNB"],
    ),
)
result = dispatch(spec, data=paxg_data)
assert len(result) == 132  # 33 策略 × 4 费率
# 与 V2 基线对比
for i, row in result.iterrows():
    assert abs(row["sharpe"] - v2_baseline[i]["sharpe"]) < 1e-6
```
