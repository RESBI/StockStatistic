- MsgpackCodec 生产启用
- Autoscaler 弹性伸缩
- drain 优雅下线
- cluster.discover 服务发现

## 6. 关键测试场景

# SharedMemory 零拷贝
shm_t = SharedMemoryTransport()
ref = shm_t.send_data(b"x" * (50 * 1024 * 1024))  # 50MB
assert ref.startswith("shm://")
data = shm_t.fetch_data(ref)
assert len(data) == 50 * 1024 * 1024

# 抢占/恢复
worker = Worker(dispatcher_url=..., preemptable=True)
task1 = client.compute.remote("backtest", ..., priority=1)  # 低优
task2 = client.compute.remote("backtest", ..., priority=-1)  # 高优
# task2 抢占 task1

# task1 恢复
task1_result = task1.wait()

# 多级 Dispatcher

assert len(topology["sub_dispatchers"]) == 1
