# P6 — 分布式集成实现规划

> **Phase**：P6
> **目标**：RemoteComputeBackend + Worker 进程 + AutoBackend + 端到端测试
> **前置依赖**：P3（Compute 核心）、P5（Dispatcher）
> **预计耗时**：1.5 周
> **测试数**：80

---

## 1. 目标与范围

实现 V3.1 的**完整分布式链路**：
- RemoteComputeBackend（通过 Transport 提交到 Dispatcher）
- AutoComputeBackend（按规模路由本地/远程）
- Worker 进程（注册/心跳/拉取/执行/回传）
- 端到端集成测试（Client → Dispatcher → Worker → Storage）
- 本地/远程结果一致性验证

## 6. 关键测试场景

```python
# 本地/远程一致性
spec = build_backtest_task_spec(data, strategy, initial_cash=10000)
local_result = local_backend.submit(spec).wait()
remote_result = remote_backend.submit(spec).wait()
pd.testing.assert_frame_equal(local_result.equity, remote_result.equity)

# E2E
dispatcher = Dispatcher(storage_url="http://storage:8000")
worker = Worker(dispatcher_url="http://dispatcher:9000", concurrency=4)
worker.start_background()
worker.wait_registered(timeout=10)

client = StockStatClient(compute_backend=RemoteComputeBackend("http://dispatcher:9000"))
task = client.compute.remote("backtest", ...)
result = task.wait(timeout=60)
assert isinstance(result, BacktestResult)

# PAXG v5-redo 分布式
task = client.compute.remote("batch_backtest", ...)
result = task.wait(timeout=3600)
assert len(result) == 132  # 33 策略 × 4 费率
```
