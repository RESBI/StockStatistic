# P1 — Foundation 基础层实现规划

> **Phase**：P1
> **目标**：建立协议底座，提供 Envelope/TaskSpec/Transport/Codec/Contracts
> **前置依赖**：无
> **预计耗时**：1.5 周
> **测试数**：147

---

## 1. 目标与范围

### 1.1 目标

建立 V3.1 的**协议底座** `stockstat-foundation` 包，包含：
- 6 个 Protocol 契约（ComputeBackend/Transport/Storage/Cache/Codec/Plugin）
- 协议层（Envelope/Headers/TaskSpec 三段式/messages/retry）
- 7 个 Codec（JSON/Arrow/Parquet/CSV/Cloudpickle/Msgpack/Raw）
- 5 种 Transport（InProcess/HTTP/SHM/Redis/TCP 骨架）
- 12 个异常类
- Config 配置体系
- PluginRegistry

### 1.2 不含

- 任何业务逻辑（BacktestEngine/indicators/handlers）
- 任何数据持久化（SQLAlchemy/ORM）
- 任何用户接口（Client/CLI）
- 任何任务调度（Dispatcher/Worker）

### 3.3 关键实现要点

**Envelope 编解码**（P1-08）：
- JSON 先尝试，失败 fallback msgpack
- bytes payload 自动 base64 + `_payload_b64` 标记
- `reply()` 透传 trace_id 和 protocol_version

**TaskSpec 三段式**（P1-07）：
- `ComputeSpec.params` dict 承载 47 个 task_type 的特定参数
- `to_dict()` / `from_dict()` roundtrip
- `DataSpec.cache_key()` 用 sha256 前 32 字节

**可选依赖优雅降级**（P1-11）：
- CloudpickleCodec/MsgpackCodec/RedisTransport 未安装时清晰报错
- 错误信息包含安装命令

### 4.2 关键测试场景

```python
# Envelope JSON + Msgpack roundtrip
env = Envelope(type="task.submit",
               headers=Headers(encoding="msgpack", trace_id="t1"),
               payload={"x": 1})
raw = env.encode()
restored = Envelope.decode(raw)
assert restored.headers.trace_id == "t1"

# TaskSpec roundtrip（含 params dict）
spec = TaskSpec(
    task_id="test-001",
    data_spec=DataSpec(symbols=["BTC/USDT"]),
    compute_spec=ComputeSpec(task_type="backtest", params={"custom": True}),
)
d = spec.to_dict()
restored = TaskSpec.from_dict(d)
assert restored.compute_spec.params["custom"] is True

# InProcessTransport 双向通信
a, b = make_pair()
a.send(Envelope(type="task.submit", payload={"test": 1}))
received = b.receive(timeout=1.0)
assert received.type == "task.submit"

# SharedMemory 零拷贝
shm_t = SharedMemoryTransport()
ref = shm_t.send_data(b"x" * (20 * 1024 * 1024), "application/octet-stream")
assert ref.startswith("shm://")
data = shm_t.fetch_data(ref)
assert len(data) == 20 * 1024 * 1024

# 可选依赖优雅降级
with pytest.raises(ImportError, match="cloudpickle"):
    CloudpickleCodec().encode({"test": 1})  # cloudpickle 未安装时
```

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| SharedMemory 跨平台兼容性（Windows） | 优雅降级到 inline；测试覆盖 Windows |
| Redis 测试需要 Redis 实例 | CI 启动 Redis 容器；未启动时跳过（6 项 skip） |
| msgpack 版本兼容 | 锁定 `msgpack>=1.0`；测试 roundtrip |
| pyarrow 版本兼容 | 锁定 `pyarrow>=14.0`；ArrowCodec 测试覆盖 |
