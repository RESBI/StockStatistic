# P4 — Invocation 用户入口实现规划

> **Phase**：P4
> **目标**：StockStatClient + ComputeAPI + DSL + CLI + V2 迁移辅助
> **前置依赖**：P1（Foundation）、P3（Compute 核心）
> **预计耗时**：1.5 周
> **测试数**：170

---

## 1. 目标与范围

建立 `stockstat` 包（Invocation 模块）：
- StockStatClient（重构，纯调用者）
- ComputeAPI（client.compute.*）
- DataClient（HTTP 访问 Storage）
- DSL 引擎
- CLI / TUI
- Export 序列化
- 可视化层（_viz）
- `_compat.py` V2 迁移辅助

## 6. 关键迁移验证

```python
# V2 旧代码（零修改）
from stockstat import StockStatClient, grid_search
client = StockStatClient(host="storage", port=8000)
result = client.backtest(data, strategy, initial_cash=10000)
result = grid_search(data, strategy, param_grid={...})

# V3.1 新代码（等价）
client = StockStatClient(storage_url="http://storage:8000")
result = client.backtest(data, strategy, initial_cash=10000)
result = client.compute.remote("grid_search", ...).wait()
```
