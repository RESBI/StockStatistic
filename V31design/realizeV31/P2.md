# P2 — Storage 存储端实现规划

> **Phase**：P2
> **目标**：OHLCV 数据持久化、查询、采集
> **前置依赖**：P1（Foundation）
> **预计耗时**：1 周
> **测试数**：125

---

## 1. 目标与范围

### 1.1 目标

建立 `stockstat-backend` 包，提供：
- SQLAlchemy ORM（OHLCV / SymbolMetadata 模型）
- StorageBackend 实现（Foundation Protocol）
- REST API（`/api/v1/ohlcv` / `/api/v1/symbols` / `/health`）
- 数据采集适配器（Binance / YFinance）
- 数据规范化（字段映射 / 时区对齐）
- 定时采集调度器
- Admin 管理面板

### 1.2 不含

- 计算逻辑（BacktestEngine/indicators）
- 任务调度（Dispatcher）
- 用户接口（Client SDK）

---

## 2. 前置依赖

- **P1 Foundation**：StorageBackend Protocol、ArrowCodec、Config

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| SQLite 并发写入限制 | WAL 模式 + 写串行化；建议生产用 PostgreSQL |
| Binance API 限流 | 测试用 mock；真实调用加 rate limit |
| YFinance 依赖稳定性 | 可选依赖；未安装时清晰报错 |
