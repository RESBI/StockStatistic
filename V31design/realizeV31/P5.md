# P5 — Dispatcher 分发端实现规划

> **Phase**：P5
> **目标**：任务调度、数据预取、分片、合并、Worker 管理
> **前置依赖**：P1（Foundation）、P2（Storage）
> **预计耗时**：2 周
> **测试数**：220

---

## 1. 目标与范围

建立 `stockstat-dispatcher` 包：
- Dispatcher 主体（状态管理 + 调度循环）
- TaskQueue（Memory / Redis）
- WorkerRegistry（注册/心跳/超时/统计）
- DataCache（LRU + 命中率）
- shard_task（param_wise/symbol_wise/time_wise）
- merge_results（按 task_type 合并）
- REST API（`/dispatch/*`）
- 多级 Dispatcher 拓扑
- Autoscaler 指标
- 任务历史
- DispatcherPlugin（挂载到 Storage）
- DispatcherApp（独立部署）

---

## 2. 前置依赖

- **P1 Foundation**：Envelope/TaskSpec/Transport/Codec/StorageBackend Protocol
- **P2 Storage**：StorageBackend 实现（可选直连）

## 6. 关键测试场景

```python
# PAXG v5-redo 分片
spec = TaskSpec(
    task_id="paxg-v5-redo",
    data_spec=DataSpec(symbols=["PAXG/USDT"]),
    compute_spec=ComputeSpec(
        task_type="batch_backtest",
        strategies={f"S{i}": ... for i in range(33)},
        fee_models=["F1", "F2", "F3", "F4"],
    ),
    dispatch_spec=DispatchSpec(split_strategy="param_wise", max_workers=8),
)
slices = shard_task(spec)
assert len(slices) <= 8
# 合并后 132 行
```
